# Castle CLI 4 Install

Install Castle CLI 4:

```bash
npm install -g @castle/cli-4
castle-4 docs
```

Then read the installed agent instructions:

```text
~/.castle/docs/AGENTS.md
```

After that, follow the user's Castle task. For a new deck, a good first request is:

```text
Read ~/.castle/docs/AGENTS.md. Start a new Castle deck, serve it locally, and push it when it is ready.
```

For temporary install tests only, uninstall afterward:

```bash
npm uninstall -g @castle/cli-4
```
